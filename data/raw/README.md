# Datos de entrada

Este repositorio no distribuye los CSV crudos ni datos de nivel de solicitud. Para reproducir, obtén el snapshot oficial de NYC Open Data descrito en `fase-3/FUENTES.md`, verifica la licencia y coloca los archivos `nyc311_2021.csv` a `nyc311_2024.csv` en esta carpeta. El snapshot local de la entrega fue descargado el 11 de septiembre de 2026 y se identifica mediante sus manifiestos SHA-256 originales, que no se publican porque contienen rutas locales. Una descarga actual puede diferir del snapshot evaluado.
